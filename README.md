# EsoData.NET

> [!WARNING]
> Created with substantial help from **OpenAI Codex** and tested against my own use cases. Please do not treat this project as a measure of my abilities as a developer, for better or worse.

A standalone .NET 10 library for reading Elder Scrolls Online addon data into C# models and generating build and crafting imports. No game client, database, MCP server, or network connection is required for local formats.

Development is underway. See subsequent commits for supported formats and examples.
